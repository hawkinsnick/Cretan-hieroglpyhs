# Cretan Hieroglyphic Open Corpus

**0.1.0 — evidence architecture and cross-script foundation**

An open, provenance-first research corpus for Cretan Hieroglyphic designed to preserve scholarly disagreement, distinguish observation from interpretation, and support reproducible comparison with Linear A, Cypro-Minoan and Linear B.

The project aims to earn trust through attribution, reproducibility, transparent corrections and conservative handling of rights. It does not claim to replace specialist editions or to establish a decipherment.

## Research family
- `hawkinsnick/Linear-A` — primary undeciphered-script research platform
- `hawkinsnick/Cypro-Minoan` — independent undeciphered corpus/adversarial architecture test
- `hawkinsnick/Linear-B` — deciphered known-answer control
- this repository — geographically/chronologically close undeciphered comparison

All remain independent repositories and release histories.

## 0.1.0
This release freezes architecture, ethics, rights, native record/assertion schemas, source-lineage rules, cross-script hypothesis rules, experiment gates and Aegean Epigraphy Interchange v0.1 conformance. It contains no claim of comprehensive inscription coverage and no decipherment claim.
