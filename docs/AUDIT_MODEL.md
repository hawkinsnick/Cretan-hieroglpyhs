# Audit model

2.0 separates four questions: **Does the catalogue record exist? Is metadata source-checked? Is a transcription source-checked? Are sign occurrences source-checked?**

Release dashboards must report these independently. A 100% catalogue spine cannot be presented as 100% epigraphic coverage.

Integrity checks include unique IDs, series/range consistency, source referential integrity, non-orphan child records, stage prerequisites, disagreement preservation, native-sign identity protection and synchronization of release metadata.
