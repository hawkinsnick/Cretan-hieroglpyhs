# Reproducibility contract — 4.0

Every published project statistic must be derivable from committed records or explicitly identified as externally sourced. Audit snapshots list their input paths. Derived analytical outputs state algorithm/version, parameters, input corpus version and exclusion rules.

A reproducible result is not automatically a correct interpretation. Reproducibility establishes that another researcher can reconstruct what the project did; provenance and scholarly review address whether the premises are defensible.

No hidden manual correction may alter a released count. Corrections enter committed data and produce a new audit.
