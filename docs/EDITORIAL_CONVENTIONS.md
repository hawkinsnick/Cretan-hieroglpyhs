# Editorial conventions — v3

Artefact, surface, graph, sign identification, transcription and interpretation are separate layers. A graph is not automatically a linguistic sign.

CHIC's published inventory is represented historically. Later proposals may add, split, merge, reclassify or exclude graphs only as separately attributed assertions. Especially on seals, competing writing/iconography classifications must remain visible.

Post-CHIC finds receive `CH-EXT-####` project IDs until an authoritative concordance is recorded; CHIC numbers are never invented. Diplomatic readings precede normalization. Damage, uncertainty, direction, segmentation and restoration are explicit. Graphic similarity to Linear A/B never licenses phonetic substitution.
