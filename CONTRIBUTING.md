# Contributing

Contributions are welcome when they improve evidence quality, provenance, interoperability or reproducibility.

For corpus data, identify the exact source and distinguish transcription from normalization and interpretation. Do not fill unknown fields by inference. Competing scholarly readings should coexist as attributable assertions.

For sign data, preserve CH native identifiers. Proposed Linear A, Linear B or Cypro-Minoan correspondences belong in cross-script claims.

For third-party images or facsimiles, document redistribution rights before committing content.

A change should update coverage metadata when it changes corpus counts or verification status. Breaking changes to stable 1.0 identifiers or evidence semantics require a migration note.
